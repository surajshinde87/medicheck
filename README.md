# 🩺 Medicheck – Online Doctor Appointment Booking Platform

**Medicheck** is a full-stack web application designed to streamline doctor appointment bookings for patients, doctors, and administrators. Built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js), the platform features role-based dashboards, real-time availability, secure Razorpay payments, and a responsive UI.

---

## 🚀 Live Demo

🔗 [Live Website Link](https://medichecks.netlify.app/) 


---

## 📌 Features

### 👤 Patient:
- Sign up & login
- Browse doctors by specialty/location
- Book & cancel appointments
- View appointment history
- Pay via Razorpay
- Get email/SMS notifications

### 🩺 Doctor:
- Personalized dashboard
- Manage schedule & fees
- Accept/reschedule/cancel appointments
- Track earnings and appointments

### 🛠️ Admin:
- Add/edit/remove doctors
- Manage doctor availability
- View system analytics
- Full control of appointments

## 🧰 Tech Stack

| Layer        | Technology                    |
|--------------|-------------------------------|
| Frontend     | React.js, Tailwind CSS, Vite  |
| Backend      | Node.js, Express.js           |
| Database     | MongoDB Atlas, Mongoose       |
| Authentication | JWT, bcrypt                 |
| Payments     | Razorpay Integration          |
| Media Storage| Cloudinary                    |
| State Mgmt   | React Context API             |
| API Calls    | Axios                         |
| Deployment   | Vercel (Frontend), Render/Heroku (Backend) |


---

## 🔐 Security Features
- JWT-based authentication for secure login
- Password hashing with bcrypt
- Input validation & API rate limiting
- Role-based route protection

---

## 💳 Payment Integration

Medicheck integrates with **Razorpay** to provide secure and seamless online payment processing for doctor consultations.
